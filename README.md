# 🍼 BÉBÉPAPA 주문 도우미

수제 이유식 & 유아식 전문점 **베베파파**의 월간 메뉴 스크린샷을 붙여넣으면, 메뉴를 인식해 항목별 수량을 토글로 조정하고(형광펜 표시), 주문용 텍스트로 추출해 주는 단일 파일 웹앱입니다.

## ✨ 기능

- **스크린샷 붙여넣기** — `Ctrl+V` / 드래그&드롭 / 파일 선택
- **자동 텍스트 인식(OCR)** — Tesseract.js(한글)로 메뉴를 인식, 3단 컬럼을 분리해 날짜 칸별로 정리
- **항목별 수량 토글** — 메뉴 이름 클릭 또는 `−/＋` 스테퍼 (0.5 단위 가능)
- **형광펜 표시** — 수량이 잡힌 항목은 노란 마커로 강조 + 날짜 칸에 선택 개수 배지
- **주문 텍스트 추출** — 날짜별로 구조화된 주문서 자동 생성 → 복사 / `.txt` 저장
- **정확 인식 경로(JSON 가져오기)** — Claude에 스크린샷을 주고 받은 메뉴 JSON을 그대로 불러오기
- **기본 6월 메뉴 내장** · **편집 모드** · 선택 상태 자동 저장(localStorage)
